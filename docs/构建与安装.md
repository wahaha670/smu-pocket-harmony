## 关键路径（改路径前必读）

工具链必须放在**纯 ASCII 路径**下，否则华为的 `restool` 会报错：

```
Error: The argument value '...' is not an ASCII value.
```

所以：

| 项 | 正确路径 |
|---|---|
| CLI 工具链 | `D:\HarmonyOS\commandline-tools\command-line-tools` |
| 工程 | `D:\HarmonyOS\smu-pocket` |
| DevEco Studio | `D:\devecostudio-windows-26.0.0.865\DevEco Studio` |

⚠️ 原来的 `D:\下载\...` 不能用 —— `下载` 是中文，会触发上面的错误。

## 环境变量（三个都要设）

```powershell
$cli = 'D:\HarmonyOS\commandline-tools\command-line-tools'

[Environment]::SetEnvironmentVariable('DEVECO_CLI_CLT_PATH', $cli, 'User')
[Environment]::SetEnvironmentVariable('OHOS_SDK_HOME',        "$cli\sdk", 'User')
[Environment]::SetEnvironmentVariable('DEVECO_SDK_HOME',      "$cli\sdk", 'User')
```

> ⚠️ `DEVECO_CLI_CLT_PATH` 要指到 **`command-line-tools` 那一层**，
> 不是它外面的 `commandline-tools`（少一层会报 `Invalid DEVECO_CLI_CLT_PATH`）。

## 🔜 下一步 1：连接手机

### 手机端

1. **设置 → 关于手机 → 连点「版本号」7 次** → 开启开发者模式
2. **设置 → 系统和更新 → 开发人员选项**：
   - 打开 **USB 调试**
   - 打开 **「仅充电时允许 ADB 调试」**（部分机型必需）
3. USB 连接电脑
4. 手机上弹出「**是否允许 USB 调试**」→ 点**允许**（勾选「一律允许」）

### 电脑端验证

```powershell
$hdc = 'D:\HarmonyOS\commandline-tools\command-line-tools\sdk\default\openharmony\toolchains\hdc.exe'
& $hdc list targets
```

**成功**：显示设备序列号，形如 `7001005458323933328C3xxxxx`

**失败排查**：
```powershell
& $hdc kill          # 杀掉 hdc 服务
& $hdc start         # 重启
& $hdc list targets  # 再查
```

如果还是空：
- 换一根**数据线**（很多线只能充电）
- 换 USB 口（优先主板后置 USB 2.0）
- 手机上确认「USB 连接方式」是**传输文件**而非「仅充电」
- 检查是否装了华为手机助手（HiSuite），它可能抢占 ADB

## 🔜 下一步 2：签名

鸿蒙**不允许安装未签名的包**。调试签名需要：

1. **华为开发者账号**（免费注册，需实名）
2. **已连接的真机**（要读设备 UDID 注册调试证书）

### 操作

```powershell
$cli = 'D:\HarmonyOS\commandline-tools\command-line-tools'
$env:DEVECO_CLI_CLT_PATH = $cli
$deveco = '$env:APPDATA\xiaoyiwork\connectors\deveco\devecocli.cmd'

# ① 登录（会打开浏览器）
& $deveco auth login

# ② 生成签名材料（必须在手机已连接时跑）
Push-Location 'D:\HarmonyOS\smu-pocket'
& $deveco signature generate --product default
Pop-Location
```

成功后会在 `$env:USERPROFILE\.ohos\config\` 生成：

| 文件 | 用途 |
|---|---|
| `*.p12` | 密钥库 |
| `*.csr` | 证书请求 |
| `*.cer` | 证书 |
| `*.p7b` | 调试 Profile（含设备 UDID） |

并自动写回 `build-profile.json5` 的 `signingConfigs`。

## 故障排查

| 现象 | 原因 / 处理 |
|---|---|
| `is not an ASCII value` | 路径含中文，见上面的「关键路径」 |
| `Invalid DEVECO_CLI_CLT_PATH` | 路径少一层，要指到 `command-line-tools` |
| `hvigor config file ... does not exist` | 缺 `hvigor/hvigor-config.json5` |
| `hdc list targets` 为空 | 见「下一步 1」的排查清单 |
| `Failed to automatically generate signatures` | 没登录华为账号，先 `auth login` |
| `error:install sign info inconsistent` | 换过签名密钥，先 `devecocli run --uninstall` |
| `Provision number exceeds limit` | 调试证书配额满，去 AGC 控制台删旧的 |
| 编译报 `arkts-no-any-unknown` | 不要用 `any`/`ESObject`，用 `Object` + `Record<string, Object>` |
| 编译报 `arkts-no-ctor-prop-decls` | 构造函数不能写 `constructor(private x: T)`，要分开声明字段 |

## 已修复的编译错误（37 → 0）

记录在此，避免以后重踩：

| # | 错误码 | 问题 | 解法 |
|---|---|---|---|
| 1 | `arkts-no-any-unknown` ×17 | 用了 `ESObject` | 全部改 `Object` + `Record<string, Object>` |
| 2 | `arkts-no-ctor-prop-decls` ×8 | `constructor(private x: T)` | 拆成字段声明 + 普通参数 |
| 3 | `arkts-no-props-by-index` | 字符串下标 `labels[i]` | 改用 `string[]` 数组 |
| 4 | `10505001` | `CardBoxHost` 未导出 | 改用 `CardBox` 尾随闭包 |
| 5 | `10905204` | `this.body()` 非 UI 语法 | 同上，用 `@BuilderParam` 尾随闭包 |
| 6 | `10905201` | `Blank` 不能在 `ListItem` 里 | 改用 `Row().height(20)` |
| 7 | `arkts-no-structural-typing` | 接口隐式匹配 | `SessionStore implements SessionStoreLike` |
| 8 | `arkts-no-untyped-obj-literals` | `AppDeps` 是 interface | 改成 `class` + 构造函数 |
| 9 | `10505001` | `tabIndex` 与内置属性冲突 | 改名 `currentTab` |
| 10 | `10505001` | `ColorMode` 类型不匹配 | 走 `prefersDark()` 统一处理 |
| 11 | `10505001` | `Configuration` 不在 `ConfigurationConstant` 里 | 单独 `import Configuration` |
