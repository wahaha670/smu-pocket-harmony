# 装到你的鸿蒙手机上 · 准备清单

> 目标机型：**HUAWEI Mate 80 Pro Max**（HarmonyOS 7.0.0.111，满足要求）
> 应用：`com.smu.pocket` v1.1.1

---

## 一、你需要做的准备（按耗时排序）

### ① 华为开发者账号 + 实名认证 ⏱ 最耗时，建议最先做

**为什么必须要**：鸿蒙**不允许安装未签名的应用**。即使是自己用、即使是调试包，
也必须有一个针对**你这台设备 UDID** 签发的调试证书。
而申请调试证书需要华为开发者账号。这一步没有替代方案。

**怎么做**：

1. 打开 <https://developer.huawei.com/consumer/cn/>
2. 右上角「注册」——用手机号或邮箱注册
3. 登录后进入「个人中心」→ **实名认证**（个人认证即可，需要身份证）
4. 认证通过后就不用管了，我来做后面的签名

> ⚠️ 实名认证通常几小时到 1 个工作日，所以**先提交认证，再去做下面的事**。

---

### ② 手机开启开发者模式 ⏱ 2 分钟

1. **设置 → 关于手机 → 连点「版本号」7 次**
   → 提示「您已处于开发者模式」
2. 回到 **设置 → 系统和更新 → 开发人员选项**，打开：
   - ✅ **USB 调试**
   - ✅ **「仅充电」时允许 ADB 调试**（部分机型叫「允许 USB 调试」）
3. 如果能看到 **「USB 调试（安全设置）」**，也建议打开
   （允许模拟点击，排查问题时有用）

---

### ③ 用能传数据的 USB 线连接电脑 ⏱ 1 分钟

- ⚠️ **很多 USB 线只能充电、不能传数据**。如果连上没反应，先换线
- 优先插**主板后置 USB 口**（不要用前面板或扩展坞）
- 插上后手机会弹窗「**是否允许 USB 调试**」→ 点**允许**
  （建议勾选「一律允许」，以后不用重复点）
- 连接方式选 **「传输文件」**，不要选「仅充电」

---

### ④ 确认手机能打开学校教务系统 ⚠️ 容易忽略

App 的数据来自 `zhjw.smu.edu.cn`。这是**校内系统**，
**很可能只在校园网内、或需要学校 VPN 才能访问**。

**先做这一步验证**：用手机浏览器打开教务系统网址。
- ✅ 能打开登录页 → 没问题
- ❌ 打不开 / 一直转圈 → App 装上去也拿不到数据
  需要连校园网或开学校 VPN

> 这一步很关键：否则装完打开是「加载失败」，会以为是 App 的问题。

| **修正正式包混淆配置** | ✅ 见下 |

### 顺手修掉的一个隐患

正式包原本开启了 `-enable-property-obfuscation`（属性名混淆）。
但本应用把数据以 JSON 落盘（`cache_snapshot.json`、`widget_data.json`），
读取时按**固定字符串字段名**取值 ——
混淆会让写入端改名、读取端按原名找不到，
表现为「**缓存读不出来、桌面卡片永远显示没课**」，而且**编译期无任何警告**。

已改为保守配置（关闭属性名/文件名/导出名混淆），并写明原因。
一个开源自用应用，混淆带来的体积收益很小，不值得冒数据静默丢失的风险。

## 三、你准备好后，我执行的步骤

```powershell
$cli = 'D:\HarmonyOS\commandline-tools\command-line-tools'
$deveco = '$env:APPDATA\xiaoyiwork\connectors\deveco\devecocli.cmd'

# 1) 登录华为账号（会自动打开浏览器，你在里面登录）
& $deveco auth login

# 2) 生成调试签名材料
#    ⚠️ 必须在手机已连接的情况下跑 —— 它要读设备 UDID 注册调试证书
Push-Location 'D:\HarmonyOS\smu-pocket'
& $deveco signature generate --product default
Pop-Location

# 3) 编译 + 签名 + 安装 + 启动（一条命令走完）
Push-Location 'D:\HarmonyOS\smu-pocket'
& $deveco run --device <你的设备序列号>
Pop-Location
```

签名成功后会在 `$env:USERPROFILE\.ohos\config\` 生成：

| 文件 | 用途 |
|---|---|
| `*.p12` | 密钥库 |
| `*.cer` | 数字证书 |
| `*.p7b` | 调试 Profile（已绑定你设备的 UDID） |

并自动写回 `build-profile.json5` 的 `signingConfigs`。

> 💡 我会先把模拟器停掉，避免 `hdc` 把包装到模拟器上。

## 四、装完之后

### 登录

1. 首次打开会看到登录页，点 **「打开教务系统登录（扫码）」**
2. 按学校页面的提示扫码登录
3. 登录成功后 App 会自动跳回主页，并拉取整学期课表

> 之后就**不需要再登录**了：整学期课表会存到本地，
> 即使登录失效，翻周、看今日课程、成绩都正常。
> 想更新数据时到「设置」里点同步即可。

### 添加桌面卡片

1. **长按桌面上的「南医大口袋」图标**
2. 点 **「卡片」**
3. 选「今明两天课程」，点 **「添加至桌面」**

卡片特性：
- 长条横向，**左右分栏**显示今天 / 明天
- 每门课显示：课程名 · 时间 · **授课老师** · **上课内容**
- 两栏可**各自独立上下滑动**（课程多时往下滑）
- 每 30 分钟自动刷新，跨零点后自动切换到新的一天

### 验证要点

| 项 | 预期 |
|---|---|
| 今日页 | 显示真实课程、网考号 |
| 课表页 | 14 节网格、每门课不同颜色、跨节合并、可切周 |
| 成绩页 | 按学期折叠、分档配色 |
| 离线 | 断网后仍能看课表和成绩 |
| 卡片 | 显示今明两天课程 + 老师 + 内容 |

## 五、可能的坑（提前说）

| 现象 | 原因 / 处理 |
|---|---|
| `hdc list targets` 看不到手机 | 换数据线；换 USB 口；`hdc kill` 后重连；确认 USB 调试已开 |
| `Failed to automatically generate signatures` | 没登录华为账号 → 先 `auth login` |
| 签名报 UDID 相关错误 | 手机没连上，`signature generate` 需要读设备 UDID |
| 装上了但打开就「加载失败」 | 大概率是**访问不到校内教务系统**，见准备清单第 ④ 条 |
| 卡片添加后不显示内容 | 先打开一次 App（触发数据写入），再到设置里点一次同步 |
| 提示「签名不一致」需要卸载旧版 | 换过签名密钥，卸载旧版本再装 |
| 调试证书配额满 | 去 AGC 控制台删掉旧的调试证书 |
