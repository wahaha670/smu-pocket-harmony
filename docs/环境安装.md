## 方案 A：装 Command Line Tools（推荐，约 1–2 GB）

**适合**：只要能编译、能装真机；不需要图形编辑器。
**优点**：体积小、纯命令行、`devecocli` 直接可用。

### A1. 下载

1. 打开 <https://developer.huawei.com/consumer/cn/download/>
2. 登录华为开发者账号（需实名认证）
3. 找到 **「Command Line Tools」**（在 DevEco Studio 下载页里，或「HarmonyOS SDK」分类下）
4. 下载 **Windows x64** 版本（`.zip`，约 300–600 MB）
5. **存到 D 盘**：`D:\HarmonyOS\commandline-tools\`

> ⚠️ 下载页是 JS 动态渲染，我这边抓不到直链。请用浏览器手动下载。

### A2. 解压

```powershell
# 假设下载到 D:\DeepSeekHarness\downloads\
Expand-Archive -Path 'D:\DeepSeekHarness\downloads\commandline-tools-windows-x64-*.zip' `
               -DestinationPath 'D:\HarmonyOS\commandline-tools' -Force
```

解压后应能看到：

```
D:\HarmonyOS\commandline-tools\
├─ bin\            (hvigorw / ohpm / hdc 等)
├─ sdk\             ← HarmonyOS SDK 本体
├─ hvigor\
├─ ohpm\
└─ ...
```

### A3. 告诉 `devecocli` 工具链在哪

`devecocli` 的文档里写明：**Command Line Tools 不会被自动发现**，
需要设置环境变量 `DEVECO_CLI_CLT_PATH`：

```powershell
# 永久写入用户环境变量
[Environment]::SetEnvironmentVariable(
  'DEVECO_CLI_CLT_PATH',
  'D:\HarmonyOS\commandline-tools',
  'User'
)

# 当前会话也生效（不重启 PowerShell）
$env:DEVECO_CLI_CLT_PATH = 'D:\HarmonyOS\commandline-tools'
```

### A4. 配置 SDK 路径

```powershell
# SDK 一般在 <CLT>\sdk
$env:OHOS_SDK_HOME = 'D:\HarmonyOS\commandline-tools\sdk'
$env:DEVECO_SDK_HOME = 'D:\HarmonyOS\commandline-tools\sdk'
```

### A5. 验证

```powershell
$cli = '$env:APPDATA\xiaoyiwork\connectors\deveco\devecocli.cmd'
& $cli device list          # 现在应该不再报 "DevEco Studio installation not found"
& $cli docs catalog         # 能列出文档目录就说明 SDK 联通
```

## 方案 B：装完整 DevEco Studio（约 5–8 GB）

**适合**：你想自己改代码、看 UI 预览、用模拟器。
**优点**：图形化、带模拟器、开箱即用。

### B1. 下载

<https://developer.huawei.com/consumer/cn/deveco-studio/>

选 **Windows 64 位**，下载 `.exe` 安装包。

### B2. 安装到 D 盘

安装向导里把路径改成：

```
D:\Huawei\DevEco Studio
```

> ⚠️ DevEco 默认装 C 盘。**务必在向导里改路径**，否则会占用 C 盘 5–8 GB。
> 如果向导不让改，先装完再用目录联接迁到 D 盘。

### B3. 首次启动配置

1. 启动 DevEco Studio
2. 它会自动下载 **HarmonyOS SDK**（这次下载到安装目录下的 `sdk\`）
3. 如果提示 SDK 路径，选 `D:\Huawei\DevEco Studio\sdk`
4. 装完后在 `Settings → SDK` 里确认已装 **API 12（5.0.0）** 或更高

### B4. 验证 `devecocli` 能找到它

```powershell
$cli = '$env:APPDATA\xiaoyiwork\connectors\deveco\devecocli.cmd'
& $cli device list
```

`devecocli` 支持的默认路径包括 `C:\Program Files\Huawei\DevEco Studio` 等。
如果你装在 `D:\Huawei\DevEco Studio`，可能需要：

```powershell
[Environment]::SetEnvironmentVariable(
  'DEVECO_CLI_CLT_PATH',
  'D:\Huawei\DevEco Studio',
  'User'
)
```

## 真机准备

1. **手机上**：设置 → 关于手机 → 连点「版本号」7 次，开启开发者模式
2. 设置 → 系统和更新 → 开发人员选项 → 打开 **USB 调试**
3. （部分机型）还要打开 **「仅充电时允许 ADB 调试」**
4. USB 连接电脑 → 手机弹窗「是否允许 USB 调试」→ 允许

### 验证连接

```powershell
# 优先用 DevEco 自带的 hdc（在 CLT 的 bin 目录）
& 'D:\HarmonyOS\commandline-tools\bin\hdc.exe' list targets

# 或者用 devecocli 的封装
& '$env:APPDATA\xiaoyiwork\connectors\deveco\devecocli.cmd' device list
```

看到设备序列号（形如 `7001005458323933328C3xxxxx`）就算连通。

> ⚠️ 目前手头那个 `小白调试助手` 的 `hdc.exe` 版本是 3.1.0e，
> 和 DevEco 的 `hdc` 可能不完全兼容。**装好 CLT/Studio 后用它们的 hdc**。

## 签名（装真机必需）

鸿蒙不允许装未签名的包。首次需要：

```powershell
$cli = '$env:APPDATA\xiaoyiwork\connectors\deveco\devecocli.cmd'

# 1. 登录华为开发者账号（会打开浏览器）
& $cli auth login

# 2. 自动生成签名材料并写入 build-profile.json5
& $cli signature generate --product default
```

它会生成到 `~\.ohos\config\`：

| 文件 | 说明 |
|---|---|
| `*.p12` | 密钥库 |
| `*.csr` | 证书请求 |
| `*.cer` | 下载到的证书 |
| `*.p7b` | 调试用 Profile（含设备 UDID） |

> ⚠️ 必须在**已连接真机**的情况下跑 `signature generate` —— 它要读设备 UDID 注册调试证书。

## 构建与安装

```powershell
$cli = '$env:APPDATA\xiaoyiwork\connectors\deveco\devecocli.cmd'
$proj = 'D:\HarmonyOS\smu-pocket'

# 编译
& $cli build --project-path $proj

# 装机并运行
& $cli run --project-path $proj

# 看日志
& $cli log --level E --from 5m --tail 200
```

产物在：

```
D:\HarmonyOS\smu-pocket\entry\build\default\outputs\default\entry-default-signed.hap
```

## 常见问题

| 现象 | 原因 / 处理 |
|---|---|
| `DevEco Studio installation not found in default locations` | 没设 `DEVECO_CLI_CLT_PATH`，见 A3 |
| `hvigor` 找不到 | CLT 没解压完整，或 `bin` 没进 PATH |
| `ohpm install failed` | 网络问题；`ohpm` 走的是华为镜像，需要能访问 `repo.harmonyos.com` |
| `error:install sign info inconsistent` | 换过签名密钥。先 `devecocli run --uninstall`，或 `signature generate --force` |
| 真机不出现 | 检查 USB 调试开关；换数据线；`hdc kill` 后重试 |
| `Provision number exceeds limit` | 调试证书配额满，去 AGC 控制台删旧的 |
