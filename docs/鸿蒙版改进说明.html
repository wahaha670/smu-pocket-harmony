鸿蒙版移植改进说明

从 Android 原版 Kotlin / Compose 到 HarmonyOS NEXT 纯 ArkTS / ArkUI
由 dsh-ppt 生成
Baseline

移植概览：一套代码，两种平台

  • 纯 ArkTS / ArkUI 重写，无 WebView 套壳、无 Kotlin 残留
  • 31 个 .ets 文件 / 8148 行（原版 Kotlin 4719 行）
  • 38 个单元测试：周次换算 / 学期代码 / JSON 解析
  • 真机验证：Mate 80 Pro Max，HarmonyOS 7.0.0.111 / API 26
  • 遵循 GPL-3.0，源码完整开放，保留原作者署名

第一部分：移植中发现的安卓侧问题

这些对原版同样适用
接口问题

两类查询的课程 ID 形态不一致

  • 整学期总表：100037TMP8493104
  • 按周查询：103868440W1172026010016411
  • 后果：按 ID 去重永远匹配不上 → 同一节课在缓存里出现两次
  • 修法：改用业务键（课程名 + 星期 + 起止节）匹配
  • 另发现：业务键也重复 46 组，因教务总表每行是一个排课任务
接口问题

上课内容字段只有按周查询才完整

  • sknrjj（上课内容）在整学期总表中仅 43/220 条有值
  • 按周查询则 16/16 全带
  • 后果：只缓存整学期数据 → 大部分课程没有内容可显示
  • 修法：以整学期为骨架，每次联网把按周数据合并进去，越用越全
数据问题

教务给的课程颜色不可用

  • 教务只提供 4 种颜色，其中蓝 #1f86c7 占 131/220 条（60%）
  • 同一门课每周换色：「呼吸系统」出现过 4 种颜色，「大学英语」3 种
  • 后果：课表大面积同色，看起来像数据缺失
  • 修法：按课程名做 FNV-1a 哈希 → 14 色调色板，冲突则线性探测
  • 实测 11 门课 → 11 种颜色，零碰撞

第二部分：鸿蒙侧新增的功能

原版没有的
鸿蒙特性

桌面服务卡片：长条左右分栏

  • 2×4 长条卡片，左栏今天 / 右栏明天
  • 每门课显示「课程名 · 时间 · 授课老师 · 上课内容」
  • 两栏各自独立上下滑动
  • 30 分钟自动刷新，跨零点自动切到新的一天
  • 点击卡片直接打开 App
体验改进

整学期记忆与离线可用

  • 登录一次缓存整学期 220 条课程，覆盖 1–20 周
  • 登录失效后仍可正常翻任意周、看成绩
  • 离线状态下今日页按真实日期实时计算当天课表
  • 副标题标注「离线缓存」，用户清楚知道数据来源
体验改进

课表可读性改进

  • 标题带月份：第 18 周 · 12月，跨月取前一个月（即周一所在月）
  • 表头星期下方显示每日日期，今天用实心圆底高亮
  • 跨月日期加小圆点提示
  • 格子里显示上课内容（弹性布局，跨多节的大格子多显示几行）
体验改进

深色模式与系统栏衔接

  • 四个页面 + 登录页 + 桌面卡片全部适配，跟随系统
  • 修掉 4 处「为浅色背景设计的深色文字」在深底上不可读
  • 底部系统栏与 App 导航栏无缝衔接，消除深色下的接缝
  • 课表色块无需另做一套：文字颜色按背景相对亮度自动选黑白
鸿蒙特性

Mate 80 Pro Max 适配（1320 × 2848）

  • 真机规格：1320×2848，6.9 英寸，dpi 480 → 约 440 × 949 vp
  • 模拟器默认 1320×2232，比真机矮 616px，按旧尺寸调的布局会在真机留白
  • 课表格子高度自适应：实测该机型只能滚动（14 节 × 62vp > 可用 616vp）
  • 一屏可见 10 节（原来 8 节），多出的高度全用于展示内容
鸿蒙特性

开课前实况窗提醒（最新）

  • 状态栏胶囊 + 锁屏卡片常驻显示距上课时间
  • 倒计时由系统每秒驱动，App 无需后台常驻
  • 提前量可配：5 / 10 / 15 / 30 分钟
  • 点击卡片直接跳回课表页
  • ⚠️ 受华为权益管控：event 只有 15 个商业场景，没有「上课」，需借用 TIMER 场景并申请权益
代码质量

移植中发现并修复的通用 bug

  • 卡片宽度溢出：width('100%') + 左右 margin = 100%+28px → 改 width('auto')
  • 点击不响应：onClick 挂在 @Component 外层，事件不穿透 → 移到内部 Row
  • 长屏设置页多 170px 空白：Scroll 默认垂直居中 → 显式 .align(Alignment.Top)
  • 深色下分档文字不可读：深绿/深红在深底几乎看不见 → 深色下提亮
技术要点

ArkUI 状态管理：三个反复踩的坑

  • ForEach 键不含内容 → 切周时 ArkUI 判定「键同=同批组件」，复用旧节点不重建
  • @Builder 按值传参不刷新 → 首帧把初始值捕获死，数据到了也不更新（改 @Component + @Prop）
  • @Observed 不能整体替换 → this.state = new AppState() 会断掉 @ObjectLink 绑定
兼容性

原版已修 bug 的完整继承

  • 固定 14 节网格（否则晚课 11–14 节整块消失）
  • 今日页与课表页解耦（课表翻周不影响今日）
  • 会话失效检测返回的登录页 HTML，而非只看 401
  • 成绩接口必须分页（total=50 但默认只返回 20 行）
  • 网考号字段是 xid，不是 xkh
